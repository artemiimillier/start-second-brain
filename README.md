# Start Second Brain

Навык для [Hermes Agent](https://hermes-agent.nousresearch.com). Помогает собрать **второй мозг**, то есть базу знаний о вашем бизнесе, чтобы агенту не приходилось в каждом новом разговоре заново объяснять, чем вы занимаетесь, что продаёте и к какой цели идёте.

Навык задаёт вам вопросы, читает ваш сайт и файлы, которые вы разрешили открыть, и собирает папку из обычных текстовых документов (Markdown, `.md`). Внутри будут карта `INDEX.md`, связанные между собой документы, правила обновления и порядок чтения для агента. От вас нужны ответы на вопросы и проверка того, правильно ли агент вас понял. Структуру и файлы он собирает сам.

Работает в двух режимах:

- **С нуля.** Заметок ещё нет, база собирается по интервью.
- **Навести порядок.** Документы уже есть, но в них беспорядок, дубли или два разных прайса. Навык сначала делает резервную копию, затем находит повторы и противоречия и спрашивает вас, какая версия действующая. Устаревшее переносится в `archive/`, ничего не удаляется.

## Установка

**Способ 1. Сказать агенту.** Напишите Hermes одной фразой:

> Установи скилл и запусти: https://raw.githubusercontent.com/artemiimillier/start-second-brain/main/SKILL.md

**Способ 2. Командой в терминале:**

```bash
hermes skills install https://raw.githubusercontent.com/artemiimillier/start-second-brain/main/SKILL.md
```

Команда скачает навык вместе с шаблонами и скриптом проверки. Навык начнёт работать с **нового** разговора: Hermes загружает список навыков при старте сессии.

## Запуск

1. Откройте Hermes в папке, где будет храниться база, например `~/second-brain`. Лучше делать это в терминале или в приложении: на шаге подключения Hermes попросит подтвердить запись во входной файл `AGENTS.md`, это его встроенная защита.
2. Напишите: **«Запусти Start Second Brain»**. Можно также вызвать команду `/start-second-brain`.
3. Отвечайте на вопросы. Агент задаёт их по одному: чем занимаетесь, продукты и цены, клиенты, денежная цель с цифрой и сроком, команда, где смотреть цифры, адрес сайта, какие файлы можно прочитать, какие решения вы уже принимали и что из них вышло. Если чего-то не знаете, так и скажите: агент запишет это в «Пробелы» и ничего не станет придумывать.
4. Проверьте пересказ «как я вас понял» и предложенную структуру папок. Файлы появятся только после вашего «да».
5. Когда появится запрос на запись `AGENTS.md`, подтвердите его («Allow once»).

**Пароли, ключи и коды доступа агенту не нужны.** В базу записывается, *где* смотреть цифры (например, «выручка — отчёт в кассе, раздел Продажи»), а не доступы к этим системам.

## Что получится

```
second-brain/
  AGENTS.md       порядок чтения для Hermes и Codex (ваши прежние инструкции сохраняются)
  CLAUDE.md       одна строка @AGENTS.md, чтобы Claude Code читал то же самое
  INDEX.md        карта: разделы и маршруты «вопрос → куда смотреть»
  RULES.md        что сохранять, где обновлять, что убирать в архив
  log.md          журнал изменений базы
  business/       о компании и команде
  products/       продукты и цены (цены хранятся только здесь)
  clients/        клиенты, их вопросы и возражения
  marketing/      каналы и продажи
  goals/          цели и планы
  numbers/        откуда брать цифры
  decisions/      решения и их итоги
  sources/        конспекты сайта и ваших файлов, оригиналы
  archive/        устаревшее (не удаляется)
```

Пример карты из тестового прогона на вымышленной кофейне:

```markdown
## Маршруты
- Рост выручки → [[goals/revenue]] → [[goals/growth-plan]] → [[numbers/sources-and-metrics]] → [[products/prices]] → [[business/company-team]]
- Меню и цены → [[products/prices]] → [[numbers/sources-and-metrics]] → [[clients/guests]] → [[decisions/experience]]

## Пробелы
- Неизвестны прибыль, себестоимость и маржинальность продуктов, почасовая загрузка точек.
```

У каждого важного документа есть шапка: откуда взяты сведения, кто их подтвердил, когда их проверяли и какой у документа статус (действующий, черновик или устарел). Для временных условий указано, с какого числа и до какого они действуют. Дата изменения файла ничего не говорит о свежести сведений: если сегодня скопировать старый прайс, действующим он от этого не станет.

Obsidian не нужен. Если захотите, откройте папку в нём как хранилище и посмотрите граф связей.

## Как проверить

Откройте **новый** разговор в папке базы и напишите одну строку про вашу цель, например:

> Хотим выйти на 3 млн рублей выручки в месяц. Помоги разобраться, что для этого нужно сделать.

Если всё собрано правильно, агент сначала откроет `INDEX.md`, по маршруту прочитает цель, цифры, продукты и команду, опишет, чего не хватает, и не станет читать всю базу подряд.

Если в папке есть записи в `decisions/`, спросите в том же новом разговоре про причину решения, например:

> Почему мы решили <что решили>?

Правильно: агент открыл `INDEX.md`, назвал файл решения, своими словами объяснил причину, что вышло и что отвергли. Неправильно: он выдумал причину или не нашёл решение, которое записано. В таком случае поправьте базу (нет маршрута или записи), а не формулировку вопроса.

Техническая проверка (нужен Python 3.9+):

```bash
python3 ~/.hermes/skills/start-second-brain/scripts/brain_check.py check ~/second-brain
```

Скрипт ничего не меняет. Он сообщает о битых ссылках, о файлах, которых нет в карте, о документах без шапки, о документах с `⚠`, которых нет в разделе «Ждёт решения владельца», а также показывает, какой входной файл Hermes загрузит в этой папке. Если навык установлен в категорию, путь будет `~/.hermes/skills/<категория>/start-second-brain/...`.

## Как база пополняется дальше

Навык не работает в фоне. Пополнять базу будет сам агент во время работы, по правилам из `RULES.md`, которые он читает благодаря `AGENTS.md`. Например, вы пишете: «С 1 октября косметический ремонт стоит 5 600 вместо 5 200, сохрани». Агент исправит цену в том единственном документе, где она хранится, отметит, с какой даты действует новое значение, и добавит запись в журнал. Второй прайс при этом не появится.

## Важно знать

- **Hermes читает входной файл той папки, в которой запущен.** В терминале это текущая папка, у бота в Telegram — рабочая папка из настроек (`terminal.cwd`). Если вы общаетесь с агентом не из папки базы, навык предложит один из двух вариантов: записать короткий указатель на базу в память Hermes или сменить рабочую папку. Он сделает это только с вашего согласия. Если `terminal.cwd` не задан или равен `.`, `auto`, `cwd`, бот работает из домашней папки. Значение читается при старте gateway: после смены перезапустите gateway (службу Hermes), иначе бот продолжит работать из прежней папки. У каждого профиля Hermes своя рабочая папка и своя память, поэтому указатель ставится для того профиля, через который вы пишете боту.
- **Одна база для нескольких агентов.** Codex читает `AGENTS.md`, Claude Code читает `CLAUDE.md` (а через него `AGENTS.md`). Им достаточно открыть ту же папку. Копия базы на другом компьютере сама не обновляется, поэтому держите одну папку или настройте синхронизацию (git, облачная папка).
- **Архив не заменяет резервную копию.** Время от времени копируйте папку базы в другое место.
- **Встроенная память Hermes** рассчитана на несколько тысяч знаков коротких предпочтений. Каталог услуг и историю компании там хранить не нужно, для этого и существует второй мозг.
